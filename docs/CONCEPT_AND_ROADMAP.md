# VibeQuest コンセプト & ロードマップ

## コンセプト

**スワイプで価値観を炙り出し、自分を理解し、価値観の合う人とつながる。**

質問カードを Tinder のように右（ワクワクする・共感する）/ 左（違う）にスワイプするだけで、
自分では言語化できていなかった価値観が浮かび上がる。それは「こういうのが好きなんだ」
「こういうふうに生きたいんだ」という自己理解の道具になり、その先で
**価値観が合う人とのマッチング**につながる。

### 価値の3層構造

| 層 | 提供価値 | 課金 |
|----|---------|------|
| 1. 発見 | スワイプ→分析→行動提案 | 無料（広告あり） |
| 2. 自己理解 | 価値観プロファイル（可視化・言語化） | 無料 / ¥200買い切りで広告除去 |
| 3. つながり | 価値観マッチング + チャット | **月額サブスクリプション** |

自己理解までは無料で完結させ、「この価値観プロファイルで誰かと出会える」体験だけを
サブスクリプションで解放する。プロファイルが充実するほどマッチングの価値が上がるため、
無料層の体験そのものが課金への動線になる。

## 価値観プロファイル（マッチングの中核データ）

各質問は既に以下のスコア次元を持っている（`lib/shared/models/question.dart`）:

- 成長スコア（growthScore）
- 自己決定理論: 自律性 / 有能感 / 関係性（SDT ×3）
- ikigai: 好き / 得意 / 世界が求める / お金になる（×4）
- Big Five: 開放性 / 誠実性 / 外向性 / 協調性 / 神経症傾向（×5）
- カテゴリ（health / career / hobby / learning / relationship / lifestyle / finance / creativity /
  sports / travel / adventure / service / mindfulness / entertainment の 14 種）

**プロファイルベクトル = 右スワイプした質問の 13 次元スコア平均 + カテゴリ親和度 14 次元**（計 27 次元）。
カテゴリ親和度は「そのカテゴリの質問に対する右スワイプ率」。
左スワイプは分母として親和度に反映される（右だけでなく「何に共感しなかったか」も価値観）。

**マッチング類似度 = プロファイルベクトル同士のコサイン類似度**。
27 次元なので pgvector は不要、SQL 関数（RPC）で十分。

## アーキテクチャ決定

| 項目 | 決定 | 理由 |
|------|------|------|
| 回答の永続化 | ローカル（shared_preferences）+ Supabase 同期 | 現状メモリのみで再起動消失。ローカルファーストでオフラインでも使え、同期でマッチングに参加 |
| 認証 | Supabase 匿名認証で開始、マッチング参加時にプロフィール登録 | サインアップ障壁ゼロでスワイプ体験に直行させる |
| マッチング参加資格 | 50 問以上回答 + ニックネーム登録 | プロファイル精度の担保と、空プロファイルのマッチング汚染防止 |
| マッチ成立 | 相互 Like | 定番メカニクス。片思い Like は相手に通知しない |
| チャット | マッチ成立ペアのみ、Supabase Realtime | マッチングを「つながり」まで完結させる最小要素 |
| 課金 | 既存 ¥200 買い切り（広告除去、entitlement: `premium`）+ 新設月額（マッチング、entitlement: `matching`） | まさみつの指示「マッチングは月額課金」。買い切りと併存 |
| 月額価格 | 仮 ¥480/月（product: `vibe_quest_matching_monthly`） | **価格はまさみつ決裁事項**。実装は entitlement ベースなので価格変更は App Store Connect 側で完結 |
| DB 適用 | マイグレーションファイル作成 + ローカル supabase で検証。**リモート適用（db push）はまさみつが手動実行** | CLAUDE.md の制約 |

## セキュリティ（RLS 方針）

全テーブル RLS 有効。

| テーブル | ポリシー |
|---------|---------|
| profiles | 本人: 全列 read/write。他人: マッチング参加者の公開列のみ（security definer な RPC / view 経由） |
| answers | 本人のみ read/write |
| likes | liker として insert、自分が関与する行のみ read |
| matches | 当事者のみ read |
| messages | マッチ当事者のみ read/insert |
